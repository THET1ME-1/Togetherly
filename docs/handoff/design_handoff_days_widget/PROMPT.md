В `design_handoff_days_widget/` лежит утверждённый дизайн двух виджетов домашнего экрана —
**«Кольцо года»** и **«Календарь лет»** — для приложения для пар. Реализуй их **точь-в-точь**.

Файлы:
- `days-widget-reference.html` — **источник истины**. Открой и прочитай целиком.
  Вся вёрстка инлайновая: каждый `style="..."` — готовая спецификация
  (hex-цвет, размер шрифта, вес, letter-spacing, line-height, padding, gap, радиус).
- `README.md` — Dart-токены, полная разбивка каждого размера по элементам, модель данных, поведение.

## Стек
Проект на Flutter. Домашние виджеты рисуются нативно:
- Android — Glance (Jetpack Compose Glance) или RemoteViews;
- iOS — WidgetKit + SwiftUI.

Данные из Flutter в виджеты — через `home_widget` (SharedPreferences на Android, App Group на iOS).
Если `home_widget` ещё не подключён — подключи и настрой App Group / provider.
Внутри Flutter-приложения те же два виджета продублируй как обычные Dart-виджеты
(`YearRingWidget`, `YearGridWidget`) для превью в разделе «Виджеты» — их пиши на Flutter,
кольцо — через `CustomPainter`.

## Жёсткие правила
1. Никакой своей интерпретации: hex-цвета, размеры шрифтов, веса, трекинг, радиусы, padding и gap
   переносить **буквально** из `README.md` / инлайн-стилей референса. Не округлять,
   не подменять на `Theme.of(context)`, если значение не совпадает точно.
2. Токены завести один раз в `lib/theme/couple_tokens.dart` — код из README, без изменений.
3. Шрифт Manrope (веса 700 и 800) подключить и в Flutter (`pubspec.yaml` assets),
   и на нативной стороне (Android `res/font`, iOS — в таргете виджета). Не подменять системным.
4. Каждый виджет реализовать **в двух размерах**: 4×2 и 2×2.
   Android: `targetCellWidth/Height` (4×2 и 2×2) + `minWidth/minHeight`,
   `resizeMode="horizontal|vertical"`. iOS: `.systemMedium` и `.systemSmall`.
   Пропорции в референсе: 4×2 = 472×224, 2×2 = 224×224 — считай их логическими px.
5. Кольцо прогресса: r=42 в системе 100×100, stroke 9 (в 2×2 — 8), `StrokeCap.round`,
   старт −90°, по часовой, заполнение `daysIntoYear / 365`. Никаких градиентов и теней.
6. Сетка точек: ровно 6 рядов × 12 точек, точка 9×9 gap 5 (4×2) и 8×8 gap 4 (2×2).
   Заливка строго по правилу из README (прожитый / текущий / впереди) —
   количество залитых точек **вычисляется из данных**, не хардкодится.
7. Ничего не добавлять от себя: ни блоков, ни иконок, ни подписей, ни градиентов, ни теней
   внутри виджета. Тексты — ровно те, что в референсе (русский), склонение «дней» через `Intl.plural`.

## Порядок работы
1. Найди, где в проекте живёт нативный слой (или создай), повтори существующие паттерны сборки.
2. Сначала сделай **«Кольцо года» 4×2** и покажи скриншот рядом с референсом.
   Не продолжай, пока не совпадут: фон, диаметр и толщина кольца, процент заполнения,
   размер числа в центре, две плитки справа.
3. Затем «Кольцо года» 2×2, затем «Календарь лет» 4×2 и 2×2 — после каждого скриншот
   и список расхождений, если есть.
4. Данные сначала замокай значениями из референса: `daysTotal=2126`, `startDate=2020-09-30`,
   `yearsCompleted=5`, `monthsCompleted=68`, `daysIntoYear=10`, `daysToNextAnniversary=355`,
   `monthsTotal=69`, `meetingsCount=412`. Потом подключи реальные источники.
5. Обновление раз в сутки в полночь: Android `WorkManager`, iOS `WidgetKit` timeline.
   Тап → deep link `togetherly://history`.
