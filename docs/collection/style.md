# Канон рисования марок

**Стилизованная цифровая гуашь.** Живопись видимым мазком, приглушённая
палитра, тональные ступени вместо растяжек. Не вектор, не мультфильм, не фото.

Прежний канон (шелкография середины века, звери с обводкой) отменён 27 августа
2026 после четырёх забракованных проб: мультяшные герои читались как чужое
приложение, а печатная фактура спорила с живописью.

## Пять правил

**Мазок видимый.** Широкая жёсткая кисть, следы не заглажены, края мазков
рваные и полупрозрачные на концах. Формы набираются пятнами краски, а не
линиями. Обводок нет нигде.

**Тон ступенчатый.** Каждый объект — три-четыре плоские ступени с жёсткими
границами, между ними нет плавных переходов. Освещённые кромки кладутся
отдельным светлым мазком поверх.

**Глубина строится тоном, а не деталью.** Замер по эталону «Перевал»: дальний
план 170 из 255, средний 115, ближний 50. Насыщенность падает так же: 44 → 22.
Разница между самым светлым и самым тёмным — 124 пункта, почти половина шкалы.

**Мягкое рядом с жёстким.** Дымка, облако, пар размыты до полного отсутствия
края; дерево, камень, доска вырезаны резко. Картинка держится на соседстве
этих двух фактур.

**Ни одной буквы.** Текст, номер, рамка и штемпель — работа кода, не
генератора. Модель, которой разрешили нарисовать букву, испортит её в четырёх
случаях из пяти.

## Разнообразие: как не нарисовать двенадцать раз один пейзаж

Единство набора держится на манере, а не на сюжете. Соседние марки обязаны
расходиться минимум по двум осям из четырёх.

**Масштаб.** Километры / комната / полметра / вид на стол сверху.

**Среда.** Дикая природа, город, интерьер, вода, стекло, дорога.

**Точка съёмки.** Снаружи вдаль, изнутри наружу, снизу вверх, сверху вниз,
вдоль конструкции.

**Свет.** Рассеянный пасмурный, направленный луч, холодная лампа, много мелких
тёплых огней, одна тёплая точка.

Правило одной тёплой точки работает не в каждой марке. Если повторить его
двенадцать раз, набор превратится в одну картинку с вариациями.

## Порядок работы

1. Эталон набора — `09-1 Перевал`. По нему выверяется размер мазка и плотность.
2. Каждая следующая марка гонится **с приложенным эталоном**, и в промпте стоит
   строка `REFERENCE` с оговоркой: подтягивать манеру, не сюжет. Без оговорки
   модель копирует композицию эталона.
3. Готовые печатные поля кладутся в `assets/collection/<год>/<сезон>/` в webp,
   имя — код и место: `09-1-pereval.webp`.
4. Марка собирается `tools/stamps/make_stamp.py`, превью уезжает в
   `docs/collection/preview/`.

## Чек-лист приёмки

- [ ] В файле нет ни одной буквы, цифры, рамки и штемпеля
- [ ] Мазок различим при 100%, края мазков рваные
- [ ] Внутри объектов тональные ступени, а не растяжки
- [ ] Дальний план светлее ближнего минимум на 100 пунктов из 255
- [ ] Нет обводок и нет чёрного контура
- [ ] Марка расходится с соседней по масштабу и по среде
- [ ] Выложена в ряд с эталоном и не выбивается по плотности краски

Последний пункт главный: поодиночке расхождение не видно, стиль уезжает
постепенно и заметен только в ряду.

## Чего в стиле нет

Фотографий и фотофактур. Векторной гладкости. Мультяшных персонажей, обводок,
глаз и улыбок. Градиентов через весь кадр. Бликов, свечения, объёмных теней.
Людей и животных в кадре. Солнца в кадре.
