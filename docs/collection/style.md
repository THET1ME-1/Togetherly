# Канон рисования марок

Стиль называется так: **шелкография середины века с акварельной подложкой**.
Задача канона — сделать так, чтобы марки, нарисованные разными моделями в разные
дни, лежали в одном альбоме и не выглядели чужими друг другу.

## Откуда взят стиль

Три референса, каждый дал своё.

**Ботаническая марка 1968 года** — мягкая размывка внутри формы, зернистый край
размывки, пыльная приглушённая краска, кремовая состаренная бумага, круглый
штемпель поверх изображения.

**«FUJI»** — композицию держит одна крупная геометрическая форма. Красный круг
солнца за горой работает якорем: он читается за долю секунды и с любого
расстояния. Плюс тяжёлый сжатый гротеск и номинал цифрой в углу.

**«Blue Bird Whirl»** — формы вырезаны, а не обведены. Две краски на кремовой
бумаге, плоские силуэты с прорезями внутри, ни одного контура, ни одного
градиента.

## Пять правил, которые нарушать нельзя

**Печать, а не рисунок.** Три плашечные краски на кремовой бумаге. Зерно офсета
по всему полю, плотность краски неровная, местами сухая кисть оставляет
пропуски. Одна краска из трёх сдвинута на 2–4 пикселя и вылезает за форму.

**Формы вырезаны.** Чёрных обводок нет нигде. Объект читается цветом и
силуэтом. Внутренние детали — прорези, через которые видно бумагу или нижнюю
краску.

**Одна размывка на объект.** Внутри формы допускается ровно одна мягкая
акварельная растяжка с зернистым краем. Больше одной — картинка расползается.

**Якорь.** Композицию держит одна крупная геометрическая форма: круг, арка,
полоса, дуга. Она занимает не меньше трети кадра и стоит за объектом.

**Ни одной буквы.** Текст, цифры, рамка, перфорация и штемпель — работа Flutter,
не генератора. Модель, которой разрешили нарисовать букву, испортит её в
четырёх случаях из пяти.

## Числа

| Параметр | Значение |
|---|---|
| Холст | 1024 × 1280, вертикаль 4:5 |
| Красок | ровно 3 плюс цвет бумаги |
| Объект по высоте кадра | 70–80% |
| Якорная форма | не меньше 33% кадра |
| Сдвиг мисрегистрации | 2–4 px, только одна краска |
| Зерно | по всему полю, различимо при 100% |
| Размывок внутри объекта | не больше одной |
| Обводок | ноль |

Изображение уходит под обрез: поля, рамки и белых отступов в файле нет.

## Порядок работы

Расхождения в стиле берутся не из промпта, а из того, что каждую картинку гонят
с нуля. Порядок против этого такой.

1. Первой генерируется **09·1 «Свитер не по размеру»**. Она эталон набора.
2. Эталон отсматривается по чек-листу ниже и при нужде переделывается.
3. Все остальные марки генерируются **с приложенным эталоном** и строкой
   `REFERENCE` в конце промпта. Без вложения эталона стиль поедет к третьей
   марке.
4. Марки одного листа гонятся подряд, одной сессией.
5. Готовые файлы кладутся в `assets/collection/2026/autumn/` под именем кода:
   `09-1.png`, `09-2.png` и так далее.

## Чек-лист приёмки

Марка не идёт в набор, пока не проходит все восемь пунктов.

- [ ] В файле нет ни одной буквы, цифры, рамки, перфорации и штемпеля
- [ ] Уникальных цветов после квантизации в 8 оттенков — не больше пяти
- [ ] Ни одной чёрной обводки по контуру объекта
- [ ] Якорная форма занимает не меньше трети кадра
- [ ] Видно зерно и неровную плотность краски
- [ ] Видно сдвиг одной краски за границу формы
- [ ] Размывка внутри объекта не больше одной
- [ ] Марка выложена рядом с эталоном и не выбивается по плотности краски

Восьмой пункт главный. Проверять на глаз каждую поодиночке бесполезно: стиль
уезжает постепенно, и заметно это только в ряду.

## Чего в стиле нет

Фотографий и фотофактур. Градиентов от края до края. Мягких теней, свечения,
объёма и бликов. Чёрных контуров. Мультяшных глаз, бровей и улыбок.
Реалистичных пропорций. Тонких волосяных линий. Больше трёх красок.
