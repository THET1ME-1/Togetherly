# Собранные марки

Здесь лежат марки в том виде, в каком их видит человек: изображение плюс рамка,
номер месяца, название и подпись. Это превью для обсуждения, не ассеты сборки.

Ассеты приложения — в `assets/collection/<год>/<сезон>/`: там чистое печатное
поле без единой надписи, рамку рисует Flutter поверх.

Собрать марку:

```
python3 tools/stamps/make_stamp.py <исходник> "НАЗВАНИЕ" "09" "ОСЕНЬ 2026 · TOGETHERLY" <файл>
```

Цвет рамки и надписей скрипт выбирает сам: считает среднюю яркость под каждым
элементом и при значении выше 138 из 255 переключается на тёмную краску. Каждая
сторона рамки считается отдельно, поэтому на светлом небе верхняя линия уходит
в тёмное, а остальные остаются светлыми.

## Названия

Марка называется местом, как в атласе: Перевал, Комната 4, Причал 2. Не глагол,
не описание погоды, не поэзия. Проверка — фраза «прислал тебе открытку „…“».
Номер ставится там, где место без него звучит слишком общо.

Осень 2026: сентябрь — Перевал, Комната 4, Двор, Платформа 3; октябрь — Чердак,
Причал 2, Оранжерея, Остановка; ноябрь — Кухня, Мост, Гараж, Маяк.
