# Кастомная сборка PocketBase с нативным SQLite

Прод работает НЕ на официальном бинаре: официальный собран с modernc
(SQLite, транспилированный в чистый Go), и под дневной нагрузкой Togetherly
глобальный мьютекс его аллокатора становился общей точкой сериализации —
записи стояли десятками секунд при свободном замке базы (дамп горутин
14.08.2026: писатель заблокирован в `modernc.org/libc.Xfree`). Нативный
C-SQLite (mattn) снял это: регистрация 20с+ → 0,2–0,3с.

Сборка (Go 1.25+, gcc; glibc места сборки должна быть не новее прода —
проверять запуском бинаря на VPS):

    CGO_ENABLED=1 go build -tags "sqlite_json sqlite_fts5" -ldflags "-s -w" -o pocketbase-cgo .

Обновление версии PB: поднять версию в go.mod → go mod tidy → пересобрать →
на VPS: `cp` поверх `/opt/pocketbase/pocketbase` (бэкап рядом) → restart.
Рядом на VPS лежат `pocketbase.modernc-0.39.11` и `pocketbase.bak-0.39.4` —
официальные бинари для отката.

`--hooksDir`/`--hooksPool` флагов у этой сборки нет: pb_hooks ищутся рядом с
data-папкой (как и было), пул JSVM зашит 15, слежение за файлами хуков
включено.
