# Материалы витрин

Снято 13.08.2026, лежит здесь, чтобы не искать по «Загрузкам» перед каждой
публикацией.

| Что | Куда идёт |
|---|---|
| `feature_1024x500.jpg` | Google Play, баннер витрины (русская страница) |
| `feature_en_1024x500.jpg` | Google Play, баннер витрины (английская страница) |
| `play/`, `play_en/` | Google Play, скриншоты телефона |
| `ios/`, `ios_en/` | App Store, скриншоты iPhone |

Размер баннера Play задан магазином — ровно 1024×500, JPEG или 24-битный PNG
без альфа-канала. Скриншоты Play принимает от 320 до 3840 пикселей по стороне,
соотношение не длиннее 2:1.

Файлы в сборку не попадают: каталог не объявлен в `pubspec.yaml`, он нужен
только для консолей. Заменяя их, кладите сюда же и правьте дату в первой
строке — иначе через месяц опять непонятно, свежие они или нет.
